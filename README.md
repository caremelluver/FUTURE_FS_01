A high-fidelity, futuristic professional portfolio designed with a **Cyberpunk 2077-inspired aesthetic**. This project showcases my skills, experience, and projects through an immersive, cinematic web experience.

---

## Key Features

- **Cinematic Hero Section**: Engaging landing page with dynamic particle effects and typewriter animations.
- **Technical Skills Showcase**: Interactive skills grid with hover effects and framer-motion animations.
- **Project Portfolio**: Categorized project showcase with detailed descriptions and tech stacks.
- **Experience Timeline**: Professional journey presented in a clean, readable vertical timeline.
- **Full-Stack Contact Form**: Integrated with a Node.js/Express backend and MongoDB for message persistence.
- **Fully Responsive**: Optimized for all devices, from desktop monitors to mobile screens.
- **Premium UI/UX**: Custom glassmorphism components, neon color palettes, and smooth transitions.

## Tech Stack

### Frontend
- **Framework**: [React.js 19](https://reactjs.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) & Vanilla CSS
- **Animations**: [Framer Motion](https://www.framer.com/motion/) & [React Type Animation](https://www.npmjs.com/package/react-type-animation)
- **Icons**: [React Icons](https://react-icons.github.io/react-icons/)
- **Particles**: [tsParticles](https://particles.js.org/)

### Backend
- **Runtime**: [Node.js](https://nodejs.org/)
- **Framework**: [Express.js](https://expressjs.com/)
- **Database**: [MongoDB](https://www.mongodb.com/) (Mongoose ODM)
- **Communication**: [Nodemailer](https://nodemailer.com/) (for email notifications)

## Getting Started

### Prerequisites
- Node.js (v18 or higher)
- MongoDB (local or Atlas)

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/caremelluver/FUTURE_FS_01.git
   cd "Personal Professional Portfolio Website"
   ```

2. **Setup Backend**:
   ```bash
   cd backend
   npm install
   ```
   Create a `.env` file in the `backend` directory:
   ```env
   PORT=5000
   MONGO_URI=your_mongodb_uri
   EMAIL_USER=your_email@gmail.com
   EMAIL_PASS=your_app_password
   ```

3. **Setup Frontend**:
   ```bash
   cd ../frontend
   npm install
   ```

### Running the Application

- **Start Backend**: `cd backend && npm run dev`
- **Start Frontend**: `cd frontend && npm run dev`
